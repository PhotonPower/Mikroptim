# ADR-0002: CUDA 12.x statt 13 wegen Tesla P100

- **Status:** ersetzt durch [ADR-0015](0015-cuda13-ohne-p100.md) (2026-10-29: P100 entfällt, CUDA 13 erlaubt)
- **Datum:** 2026-10-18

## Kontext
Zielhardware: RTX 3090 (sm_86) für Entwicklung, Tesla P100 (sm_60) als FP64-Rechner. CUDA 13 unterstützt Maxwell, Pascal und Volta nicht mehr.

## Entscheidung
CUDA Toolkit 12.x, empfohlen 12.9. `CMAKE_CUDA_ARCHITECTURES = 60-real;86-real;86-virtual`. CMake bricht bei CUDA ≥ 13 mit Fehlermeldung ab.

## Konsequenzen
Keine Features oberhalb sm_60 ohne Fallback. Treiber auf dem P100-Rechner dürfen nicht über die letzte Pascal-fähige Serie hinaus aktualisiert werden. Ein Wechsel auf CUDA 13 erfordert eine neue ADR und den Verzicht auf die P100.
